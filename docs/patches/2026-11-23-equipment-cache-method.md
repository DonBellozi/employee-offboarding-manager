## Причина и исправление

Главная страница и обновляемый фрагмент списка вызывают
`DismissalDetailsCacheService.attach_equipment_summaries`, но в текущем
сервисе метод отсутствовал. Из-за исключения список не отображался.

Восстановлено пакетное чтение индикаторов IT Invent из локальных снимков:
один SELECT на список, привязка к работнику и конкретной дате события,
без запросов к внешним системам и без постановки новых заданий при открытии страницы.
Нет снимка или есть ошибка проверки — отсутствие оборудования не утверждается.
Устаревшие сведения явно помечаются. Старые снимки версии 1 поддерживаются
до следующего фонового обновления.

Фоновое формирование снимка снова сохраняет количество оборудования и признак
устаревшего результата. Поведение импорта, его проверки относительно запуска
процесса, очереди фонового обновления и блокировок не изменяется.

Тест индикатора теперь автономен: удалена зависимость от отсутствующего в HEAD
`test_account_requirement.py`. Главная страница и фрагмент проверяются через
зарегистрированные обработчики и настоящие Jinja-шаблоны на тестовой БД,
без HTTP-сокетов. Зависимости проекта не добавлялись.
