# Переход от решения оператора к созданию учётных записей

Проверено по актуальному HEAD `e61c05a93f8e7db4075edfff8ecbe1379de951df`.

После нажатия «Учетная запись нужна» содержимое рабочего окна заменяется
экраном «Проверка и создание учётных записей». Блок решения и ручного
сопоставления больше не остаётся над формой создания. ФИО, личный email,
предлагаемый логин и почтовый домен заполняются прежним механизмом.

До решения ручное сопоставление доступно в свёрнутом блоке «Если учётные
записи уже выдали вручную». На экране создания ссылка «Изменить решение»
открывает решение в том же окне; вернуться к созданию также можно без
закрытия окна. Заголовок окна следует за текущим экраном, прокрутка
сбрасывается в начало при переходе.

Решение по-прежнему сохраняется существующим обработчиком вместе со снимком
кадровых данных и историей для обучения. Для создания требуется отдельное
нажатие «Создать учетные записи». Обработчики создания, проверка доступа,
CSRF, проверка версии решения и сопоставление существующих учёток не менялись.

## Проверка

- `py_compile` нового файла тестов.
- 88 pytest: переход после реального POST решения, сохранение истории,
  повторное открытие, исправление решения, отрицательное решение,
  уточнение, устаревшая версия, CSRF и недоступность каталога; существующие
  проверки приёмов, недостающей почты и рабочих окон.
- Разбор Jinja-шаблонов, синтаксис встроенного JavaScript и
  `node --check app/static/workspace_modal.js`.
- Браузерная проверка на тестовых данных: одно рабочее окно, смена экрана
  и заголовка, предзаполнение, доступность кнопки после проверки логина,
  переход к исправлению решения и обратно, ширина 1440 и 390 пикселей,
  отсутствие ошибок JavaScript. Ответы внешних систем подменены;
  реальные учётные записи и письма не создавались.

## Установка

Распаковать ZIP в корень существующего проекта с заменой файлов.
Пересобрать и пересоздать контейнер приложения обычным способом.
Миграция базы данных не требуется. Удалений нет.

Состав: четыре изменённых файла интерфейса, новый тест и эта памятка.
Записи в GitHub не выполнялись.
