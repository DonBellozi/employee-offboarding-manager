# Мягкое пульсирование отметки имущества

В «Ближайших увольнениях» отметка «Оборудование · N» плавно пульсирует рыжим
цветом, используя ту же CSS-анимацию, что и карточка имущества на странице
«Блокировка»: цикл 2,2 секунды, плавное усиление фона и подсветки рамки.
Текст не исчезает, размеры отметки не меняются.

Анимируется только отметка с найденным оборудованием, включая последний
сохранённый результат с пометкой «устарело». Нулевое количество, отсутствие
проверки и ошибка проверки не пульсируют. Предварительные строки остаются бледными.
При системной настройке уменьшения движения анимация отключается, остаётся
обычная статичная жёлтая отметка.

Запросы, кэш, письма, отсрочки и блокировка учётных записей не изменены.
Новых зависимостей и миграций БД нет. Версия ссылки на CSS обновлена.

Архив: два изменённых файла, новый тест и эта инструкция, пути относительно
репозитория. Применять поверх предыдущей доработки индикатора имущества.
Удалений нет. В GitHub изменения не отправлялись.

Пересобрать существующий Docker stack `account_provisioner_mvp`, сохранив
переменные окружения и тома данных, затем обновить страницу браузера.

Проверки: 77 профильных pytest предыдущей доработки; четыре теста CSS-анимации,
пять тестов обновления списков; Jinja и JavaScript syntax checks. В отдельном
headless-браузере проверены вычисляемые стили: общая анимация с «Блокировкой»,
изменение фона по фазам, неподвижность остальных отметок и отключение движения
при `prefers-reduced-motion`. Проверены целостность ZIP и SHA-256.
