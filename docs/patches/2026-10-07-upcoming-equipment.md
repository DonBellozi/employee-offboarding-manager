# Имущество в ближайших увольнениях

Под ФИО увольняющегося добавлена компактная отметка IT Invent:

- **Оборудование · N** — жёлтая отметка с количеством закреплённых единиц.
- **Оборудования нет** — нейтральная отметка после успешной проверки.
- **Оборудование: не проверено / нет данных / ошибка проверки** — отсутствие
  достоверного результата не выдаётся за отсутствие имущества.
- **· устарело** — показан последний результат при задержке фонового обновления,
  изменении кадровых данных или использовании устаревшего результата IT Invent.

Подсказка при наведении содержит сведения о проверке и времени снимка.
Имеющаяся кнопка «Подробности» остаётся на месте. Индикатор есть и у предварительных
увольнений; бледное оформление предварительной строки сохраняется.

## Данные и ограничения

Страница и её периодический фрагмент читают существующие `DismissalDetailsSnapshot`:
один дополнительный запрос к локальной БД на весь список, без обращений к IT Invent,
AD или почте и без постановки новой проверки по факту просмотра страницы.
Снимок выбирается строго по паре `worker_key + dismissal_date`.

Сведения обновляет прежний фоновый обработчик; открывать «Подробности» для этого
не нужно. Индикатор обновляется вместе со списком (обычно раз в 30 секунд).
Устаревшим считается снимок старше 10 минут либо с изменившимися исходными данными.

В новые JSON-снимки добавлены необязательные `equipment_count` и `equipment_stale`.
Прежние снимки версии 1 поддерживаются сразу: количество читается из прежней
строки «Есть — N шт.», отсутствие — из успешной строки «Отсутствует».
Миграция БД не требуется.

Это отметка наличия закреплённого имущества, а не утверждение о просроченной
задолженности. IT Invent остаётся read-only. Сроки, отсрочки, письма и правила
блокировки по организациям не меняются; имущество не становится условием блокировки.

## Установка

Архив содержит только 6 изменённых и 2 новых файла с путями относительно репозитория.
Применить поверх актуальной локальной версии проекта с предыдущими доработками.
Удалений нет. В GitHub изменения не отправлялись.

После замены файлов пересобрать и перезапустить существующий Docker stack
`account_provisioner_mvp`, сохранив его переменные окружения и тома данных.
Простой рестарт старого образа не применит изменения исходников.
Версия ссылки на CSS обновлена, чтобы браузер загрузил новые стили.

## Проверки

- 31 новый тест: готовые/старые/повреждённые снимки, ошибки, отсутствие сведений,
  предварительные увольнения, отсутствие внешних запросов/записей, один запрос на
  пакет, привязка к событию, оба HTTP-экрана, экранирование подсказки и обновление.
- 77 релевантных pytest прошли; расширенный запуск — 737 тестов и ещё 33 в
  изолированных процессах (шесть старых наборов подменяют модули глобально).
- Два старых набора `test_worker_identity.py` и `test_zimbra_protection.py`
  исключены из расширенного запуска: в предыдущей проверке исходной версии
  подтверждены 9 существовавших сбоев, не относящихся к этой доработке.
- `py_compile` изменённых Python-файлов и нового теста; рендеринг Jinja обоих
  экранов, JavaScript syntax check и 5 тестов обновления списков.
- Визуальная проверка выполнена на тестовых данных, без подключения к рабочей
  инфраструктуре. ZIP проверен на целостность, состав и совпадение содержимого
  с файлами проекта; вычислен SHA-256.
